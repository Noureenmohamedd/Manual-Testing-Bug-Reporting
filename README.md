# Manual Software Testing & Bug Reporting

## Project Overview
This project demonstrates hands-on experience in software testing, including test case design, test execution, defect identification, and bug reporting.

The project focuses on testing Java-based components and validating their functionality against expected behavior.

## Modules Tested

### 1. Year Class
- Tested constructors and methods.
- Validated boundary values and invalid inputs.
- Tested exception handling.
- Identified defects related to input validation and unexpected behavior.

### 2. Discount Calculator
- Tested discount calculations for different scenarios.
- Verified expected results against actual outputs.
- Identified calculation and date validation issues.

### 3. Discount Manager
- Tested price calculations and discount application.
- Validated normal and edge-case scenarios.
- Documented incorrect calculation results.

## Testing Techniques
- Functional Testing
- Boundary Value Analysis
- Positive Testing
- Negative Testing
- Test Case Execution
- Defect Identification & Reporting

## Test Documentation
Test results were documented using:
- Test Case
- Expected Result
- Actual Result
- Pass/Fail Status
- Notes and Defect Descriptions

## Key Findings
The testing process identified several issues, including:
- Incorrect handling of invalid inputs.
- Boundary condition defects.
- Incorrect discount calculations.
- Unexpected exception handling behavior.
